GitHub Pages 示例网站
=====================

上传方法：
1. 解压 github-pages-sample.zip。
2. 打开您的 GitHub Pages 仓库。
3. 点击 Add file -> Upload files。
4. 选中解压后的所有内容：index.html、about.html、contact.html、
   styles.css、script.js 和 assets 文件夹。
5. 点击 Commit changes。

重要：请上传 ZIP 里面的文件，而不是直接上传 ZIP 文件。
index.html 必须位于仓库根目录。

修改建议：
- 修改 HTML 文件里的网站文字。
- 修改 contact.html 里的电子邮件与 GitHub 地址。
- 在 styles.css 中调整颜色和排版。
